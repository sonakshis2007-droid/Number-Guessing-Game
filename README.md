# Number Guessing Game in C

A simple command-line number guessing game written in C. The program picks a random number, and the player tries to guess it.

## How to Play

1. Run the program.
2. Enter guesses when prompted.
3. Follow the hints to guess the secret number.
4. Keep going until you find it!

## Requirements

- A C compiler, such as GCC
- A terminal or command prompt

## Compile and Run

### Linux or macOS

```bash
gcc [source-file].c -o number_guessing_game
./number_guessing_game
